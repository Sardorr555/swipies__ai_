Управление Swipies из внешнего ИИ-чата: Codex, Claude Code, Cursor и другие клиенты. Проверено 2026-10-28.
Источники: https://swipies.app/llms.txt ; https://swipies.app/agents.html#automatic-access ; https://api.swipies.app/api/v1/agent-access/manifest
ИИ с разрешёнными HTTPS/API-инструментами или кодом с сетевым доступом может прочитать инструкции, приватно сохранить случайный регистрационный секрет и вызвать bootstrap. Он создаёт отдельный Free-аккаунт либо повторно подключает сохранённую личность. Для существующего аккаунта нужны его авторизованные реквизиты. Подключение к чужому или платному аккаунту не происходит автоматически. API-ключи не присылают в публичный чат. Bootstrap и исполнение идут через HTTPS. MCP как установленное подключение клиента — дополнительный способ; для документированного прямого HTTP-пути ручная установка MCP не нужна.
Операции: датасеты, документы, чатботы, агенты и поддерживаемые tenant-ресурсы; точный каталог нужно обнаруживать в текущем API. Администрирование, платежи, управление токенами и Ads вне общего MCP-каталога. Чтение сайта само по себе не добавляет ИИ сетевые инструменты или разрешения. Клиент только с чтением веб-страниц может нуждаться в настроенном подключении. Правила хоста и лимиты аккаунта сохраняются. Этот консультант не имеет инструментов и не выполняет эти операции сам.
