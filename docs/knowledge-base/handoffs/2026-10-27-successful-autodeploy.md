## Следующие релизы

Обычный push в `swipies_26` запускает `.github/workflows/deploy_main.yml`. Коммиты с `[skip ci]` пропускают автоматический запуск; ручной `workflow_dispatch` работает. Пути `atmos payment system/**` и `landing_swipies/**` исключены из этого workflow.

Деплой создаёт backup, собирает frontend, перезапускает приложение и проверяет готовность. Если проверка запрещает dirty checkout, сначала нужно сохранить и включить серверные изменения в Git. Автоматическое стирание правок отключено.

При перезапуске наблюдался короткий период HTTP 502 до готовности API: инициализация приложения занимала около 70 секунд. Текущий процесс предусматривает перезапуск одного экземпляра API; бесшовное обновление здесь не реализовано.

Внешняя CRM пока не подключена и её реальная доставка данных не проверялась. Ads проверен запросами чтения без платёжных действий; управление Ads через MCP остаётся вне текущего каталога. Проверка не является полным тестом каждого маршрута платформы.
