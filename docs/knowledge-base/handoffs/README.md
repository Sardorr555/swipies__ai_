## 1. Назначение журнала передач (Handoffs)

Каждый раз, когда разработчик или автономный AI-агент завершает рабочий сеанс, спринт или передает задачу следующему участнику (человеку или другой сессии LLM), в каталог `docs/knowledge-base/handoffs/` помещается дамп контекста — **Handoff Document**.

Это гарантирует:
- **Сохранение рабочего контекста без потерь** при очистке контекстного окна AI-модели.
- **Мгновенный ввод нового инженера в задачу** за 2-3 минуты чтения последнего отчета.
- **Прозрачность выполненной работы и воспроизводимость тестов**.

---

## 2. Именование и правила оформления

1. Формат имени файла: `YYYY-MM-DD-<краткая-тема>-handoff.md` (например, `2026-10-15-crm-and-knowledge-base-handoff.md`).
2. Обязательное использование шаблона: [Шаблон передачи контекста](../templates/handoff-template.md).
3. Документ передачи должен содержать:
   - Точный хеш текущего коммита Git и имя рабочей ветки.
   - Список затронутых файлов с номерами строк.
   - Команды проверки работоспособности (тесты, линтеры) и их фактический статус.
   - Незавершенные пункты и технические блокеры.
   - Четкие рекомендации для следующего исполнителя: **с чего начать работу**.
