# Project

An advanced web and backend application platform.

## Features
- AI Agent & RAG engine capabilities
- Deep document understanding & processing
- Multilingual web frontend
- Scalable microservices infrastructure

## Quickstart

### Prerequisites
- Python 3.10+
- Node.js 18+
- Docker & Docker Compose

### Backend Setup
```bash
uv sync --python 3.13 --all-extras
```

### Frontend Setup
```bash
cd web
npm install
npm run dev
```

### Docker Deployment
```bash
cd docker
docker compose up -d
```
