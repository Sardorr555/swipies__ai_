# RAGFlow Setup Scripts

Коллекция скриптов для быстрой настройки RAGFlow.

## 📜 Доступные скрипты

### `setup-google-oauth.sh`

Автоматическая настройка Google OAuth для RAGFlow.

**Использование:**

```bash
bash scripts/setup-google-oauth.sh
```

**Что делает скрипт:**

1. ✅ Проверяет существующую конфигурацию
2. ✅ Создает резервную копию `.env` (если существует)
3. ✅ Запрашивает Google OAuth credentials
4. ✅ Создает файл `docker/.env` с правильными настройками
5. ✅ Проверяет Docker
6. ✅ (Опционально) Перезапускает контейнеры
7. ✅ Проверяет работоспособность OAuth

**Требования:**

- Docker и Docker Compose установлены
- Google OAuth Client ID и Client Secret
- Запуск из корневой директории проекта

**Пример:**

```bash
$ bash scripts/setup-google-oauth.sh

===================================================
Настройка Google OAuth для RAGFlow
===================================================

ℹ Шаг 1: Проверка конфигурации...
ℹ Шаг 2: Ввод учетных данных Google OAuth

Введите Google Client ID: 123456789-abc.apps.googleusercontent.com
Введите Google Client Secret: ********
Введите Redirect URI: https://swipies.app/v1/user/oauth/callback/google

✓ Файл .env создан успешно
✓ Docker установлен

ℹ Шаг 5: Перезапуск Docker контейнеров...
Хотите перезапустить контейнеры сейчас? (y/n) y

✓ Контейнеры запущены
✓ OAuth endpoints доступны

===================================================
Настройка завершена!
===================================================

🎉 Готово! Пользователи могут входить через Google!
```

## 🛠️ Создание собственных скриптов

При создании новых скриптов следуйте этим правилам:

1. Используйте шебанг `#!/bin/bash`
2. Добавьте `set -e` для автоматического выхода при ошибках
3. Используйте цветной вывод для лучшей читаемости
4. Добавьте подробные комментарии
5. Проверяйте предварительные условия
6. Создавайте резервные копии при изменении существующих файлов
7. Добавьте документацию в этот README
